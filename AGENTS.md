# 4sight - CLI Coding Agent

4sight is a WIP tool to bootstrap and manage a personal development project with
an internal lightweight ticketing system, opinionated coding conventions,
scaffolding for an agentically coded application, context management, feature
breakdown, and task execution of the breakdown.

4sight development will itself be managed by 4sight.

## 4sight binary tool assists this repo

You must read .4sight/AGENTS.md which describes the 4sight management of this
repo.
